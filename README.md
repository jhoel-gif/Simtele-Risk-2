# SIMTELE-RISK — Semana 2 — GitHub Pages

Versión estática del proyecto para publicación gratuita con GitHub Pages.

## Archivos
- `index.html`: aplicación completa en HTML + CSS + JavaScript.
- No requiere Python, Flask, SQLite ni servidor.
- La persistencia del historial se realiza con `localStorage`.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `SIMTELE-RISK-Semana2`.
2. Sube `index.html` y `README.md` a la rama `main`.
3. En GitHub entra a Settings → Pages.
4. En Build and deployment selecciona `Deploy from a branch`.
5. Branch: `main`; carpeta: `/ (root)`.
6. Pulsa Save.
7. Espera unos minutos.
8. GitHub mostrará una URL del tipo:
   `https://TU-USUARIO.github.io/SIMTELE-RISK-Semana2/`

## Nota
Los datos son sintéticos y de demostración académica. La versión estática conserva la funcionalidad numérica y la demostración de persistencia en el navegador, pero la persistencia no es una base de datos centralizada: cada navegador guarda su propio historial.
